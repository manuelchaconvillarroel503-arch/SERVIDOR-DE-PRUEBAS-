# Servidor de pruebas

Repositorio de trabajo para organizar retos, guías y materiales de práctica sobre Linux, sistemas operativos y pruebas de servidores.

## Objetivo

Mantener los documentos del proyecto en un solo lugar, con nombres claros y una estructura fácil de ampliar. El archivo original de cada actividad se conserva en formato PDF.

## Contenido

Consulta el [índice de documentos](docs/README.md) para ver cómo están organizados los materiales.

## Organización de materiales

- Guarda los retos y actividades en `docs/retos/`.
- Usa nombres breves, descriptivos y en minúsculas; separa las palabras con guiones.
- Conserva la extensión correspondiente al formato del archivo, por ejemplo `.pdf`, `.docx` o `.md`.
- Añade cada nuevo documento al índice de `docs/README.md` y, si es un recurso principal, a la tabla de contenido de este README.

## Estado

El repositorio está iniciado con el primer documento. La estructura puede crecer por temas a medida que se incorporen nuevas guías o prácticas.
